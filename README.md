# Quantitative Trading & Systematic Portfolio Research

Repositorio de investigación cuantitativa enfocado en el diseño, validación y gestión de carteras de trading algorítmico (con objetivo de despliegue en Darwinex Zero).

## Objetivos del Proyecto
- Desarrollar e implementar sistemas sistemáticos en Python sin sesgo de ejecución ni sobreajuste (*overfitting*).
- Evaluar técnicas de asignación de capital (Risk Parity, Volatility Targeting) y salidas dinámicas.
- Aplicar pruebas rigurosas de robustez estadística (Monte Carlo, matrices de estabilidad).
- Documentar el proceso de investigación y construcción de un track record auditable.

## Estructura
- `src/`: Módulos de lógica cuantitativa, indicadores y gestión de riesgo.
- `notebooks/`: Cuadernos de experimentación, backtesting y análisis visual.
- `data/`: Datos históricos de mercado (almacenamiento local).
